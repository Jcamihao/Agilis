# Agilis 1.1.0

Data: `2026-04-27`

## Resumo

A versao 1.1.0 fortalece a base de autenticacao e adiciona configuracoes por usuario, alem de revisar a experiencia visual das principais telas operacionais.

## Entregas principais

- sessoes de autenticacao persistidas com `sessionId` no JWT
- logout com invalidacao da sessao no backend
- rate limit declarativo para rotas sensiveis
- modulo de settings no backend para preferencias do usuario autenticado
- pagina de configuracoes no frontend
- guards, interceptors e servicos de auth atualizados para o novo fluxo
- dashboard, planner, focus, tasks e users revisados visualmente
- novas migracoes Prisma para sessoes e configuracoes

## Impacto esperado

- autenticacao mais controlada e previsivel
- menor exposicao a abuso em endpoints sensiveis
- experiencia mais completa para ajustes individuais do usuario
- telas principais mais consistentes visualmente
